## Slide 2 · 例题：窗口重叠（不用结构体的写法）

**【先把题意和坐标讲清楚，建议画图】（0:00–0:54）**

每个窗口给 4 个数：left、right、top、bottom，分别是左边、右边、上边、下边的位置。画两个矩形，一个黑色、一个红色，部分重叠，把 8 条边都标上 win1.left、win2.left……

注意：这里的坐标是"反的"，和屏幕坐标一样，y 轴向下。所以 left 比 right 小，**top 比 bottom 小**（top 更靠上，数值反而更小）。学生按数学课的坐标系去想，很容易把 top 和 bottom 搞反，这一点要先讲。

**【重叠部分的四条边怎么来】（0:54–1:48）**

看图上中间重叠的那一块：
- 它的左边，是两条 left 里**大**的那一条：`max(l1, l2)`
- 它的右边，是两条 right 里**小**的那一条：`min(r1, r2)`
- 上边同理，取两个 top 里大的：`max(t1, t2)`
- 下边取两个 bottom 里小的：`min(b1, b2)`

让学生对着图自己说出来"为什么是 max、为什么是 min"，再写代码。有了这四个式子，程序就很好写了。

**【不重叠的情况】（4:05–4:36）**

答案一开始要设成 0，因为两个窗口可能根本不相交。怎么判断不相交？算出来的"重叠矩形"如果 left 比 right 还大（或 top 比 bottom 还大），那它就不是一个正常的矩形，说明不相交，面积就是 0。所以只有 `l3 < r3 && t3 < b3` 时才算面积。

**【⚠ PPT 小错误】**

第二段代码最后 `return 0` 少了分号。

## Slide 5 · 例题：窗口重叠（结构体写法）

**【定义结构体 win】（1:56–2:29）**

一个窗口有 4 个位置：左、右、上、下，正好打包成一个结构体 `win`。这道题要几个 win？两个输入的窗口 w1、w2，再加一个表示重叠部分的 w3，一共 3 个。

**【为什么要写一个 read 函数】（2:29–2:45）**

读一个窗口和读第二个窗口的方式完全一样，所以我们希望用统一的写法，就写一个自定义函数 `read`，读 w1 调一次、读 w2 调一次。

**【为什么参数要加 &】（2:45–3:19）**

参数写成 `win& w`，是引用传递。这样函数里 `cin >> w.l ...` 读进来的值，直接就写到了调用时传进来的 w1 / w2 身上。如果不加 &，函数里读的是一份副本，函数结束副本就没了，w1 还是空的。

**【另一种写法：函数返回一个结构体】（3:19–4:05）**

也可以这样写：

```cpp
win read(){
    win temp;
    cin >> temp.l >> temp.r >> temp.t >> temp.b;
    return temp;
}
...
w1 = read();
w2 = read();
```

这样也对。区别是：return 的时候会把 temp 复制一份新的出来；而引用的写法是直接在原来的结构体上操作，更省内存。所以 PPT 上用的是引用的写法。（视频里提到，这个区别等以后讲指针和函数返回值时会更清楚。）

**【计算与判断】（4:39–6:13）**

`w3.l = max(w1.l, w2.l)`，`w3.r = min(w1.r, w2.r)`，`w3.t = max(w1.t, w2.t)`，`w3.b = min(w1.b, w2.b)`。然后判断 `w3.l < w3.r && w3.t < w3.b` 才有重叠，面积 = `(w3.r - w3.l) * (w3.b - w3.t)`，也就是两条边相乘。

**【收尾的一句话】（6:20）**

这道题的关键就两件事：一是把问题分析清楚（重叠部分四条边分别怎么取）；二是把结构体用好，程序就写得很漂亮。可以让学生对比 Slide 2 的 12 个变量和这里的 3 个 win，体会结构体的好处。
